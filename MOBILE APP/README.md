# Next Level Gaming & Esports Arena - Mobile App Prototype

## Run it in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` > **Open with Live Server**.
   (Or just double-click `index.html` to open it in your browser.)
4. On desktop it shows inside a phone frame. Open the Live Server address on your phone (same Wi-Fi) for the full-screen app.

## Files
- `index.html` - page shell
- `styles.css` - brand colours, layout, components (edit the `:root` variables to re-theme)
- `app.js` - package data, screens, fee calculator and booking logic

## Easy edits
- Packages, prices, descriptions: the `PKGS` array at the top of `app.js`
- Team members: the `TEAM` array
- Contact details: search for `+27 (0) 10 000 0000` in `app.js`
- Logo: replace the `logo()` function with an `<img src="logo.png">`
